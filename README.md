## 这是什么

一套花了几年（2021–2025）构建的、自洽的「界域」象征宇宙，做成了一个可视化小程序：

- **每个数字 = 一个界**（0~303）：1 地狱、3 人间、4 魔界、7 天使、9 仙佛……
- **每种颜色有脾气**：白=天道之光、红=永恒魔、绿=自由快乐魔、黑=丧尸/法老、蓝=海纳百川……
- **每个字母是一界**（作者**精神探索**所得，非武秀琴）：A 正常、B 丧尸、N 大道自然、G 阴阳平衡……
- **一条 grounding 大法**（武秀琴理论）：连接各界有伤身体，必须先「如如不动 · 化掉欲望」。

> 这不是占卜，也不是科学。它是一面好玩的镜子、一件个人艺术品。

## 运行方式

### 方式一：直接用打包好的 exe（推荐，免环境）

下载 `dist/界域分析仪.exe`，双击即用。单文件，不依赖 Python，可拷给任意 Win10/11。

### 方式二：从源码运行

```bash
# 需要 Python 3.8+，依赖 Pillow、winsdk（OCR 用）
pip install pillow winsdk
python realm_gui.py
```

依赖：`tkinter`（标准库）、`Pillow`、`winsdk`（Windows OCR，可选；缺失时 OCR 自动跳过不报错）。

### 自行打包 exe

```bash
pip install pyinstaller
pyinstaller --noconfirm --clean --onefile --windowed --name 界域分析仪 \
  --collect-all winsdk --hidden-import ocr --exclude-module numpy realm_gui.py
```

## 象征体系速览

### 数字
逐位 0~9 各有含义；凡带 **2 / 4 / 6 / 8** 的位 = 不平衡 / 混乱 / 肮脏；`0` = 外循环·大循环（人世间，带地狱沉沦底色）。
大数按「**最大位逐级压最小位**」解读，末两位查界字典。

### 颜色（部分）
- 白 = 天道之光（人间的白最美）
- 红 = 永恒魔　绿 = 自由快乐魔　黑 = 鬼界/地狱·一切集合
- 蓝 = 海纳百川　金 = 主财　灰 = 阳丧尸
- 组合：蓝红白→天朝上国、**绿白红→Amelie 界**、黑红→法老诅咒、白白白→无色界

### 界字典（0~303）
- **1~218、300~303**：作者亲历确认。
- **219~299**：按数字规律**自动推理**的「推理界」，已明确标注 **不可信**。
